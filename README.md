# Nilson Portfolio Website

A responsive, modern portfolio website for AI Automation + Cybersecurity.

## Files
- index.html
- style.css
- script.js
- assets/profile.jpg

## Before publishing
1. Replace `your-email@example.com` in `index.html` with your real email.
2. Check your LinkedIn and GitHub links.
3. Add your real certification links/certificate images if desired.
4. Add screenshots/GitHub links to each project.

## Run locally
Just double-click `index.html` to preview it in a browser.

## Deploy
This is a static website, so it can be deployed to Vercel, Netlify, GitHub Pages, or most web hosting providers.
